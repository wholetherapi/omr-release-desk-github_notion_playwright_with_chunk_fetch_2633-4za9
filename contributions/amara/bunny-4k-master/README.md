# Big Buck Bunny - 4K master package

Delivery for the archive re-release programme.

- Feature master: 4096x2160, 24 fps, ProRes 4444
- Audio: 5.1 surround rebuilt from the original stems
- Subtitles: English SDH and Latin American Spanish
- QC: frame-by-frame scan completed, no dropped frames observed

The master was conformed against the 2008 festival reference print. Every colour
decision was signed off by the restoration lead.
